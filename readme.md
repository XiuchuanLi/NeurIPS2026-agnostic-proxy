## Usage

Install kerpy (a package adapted from https://github.com/oxcsml/kerpy)

```(bash)
cd kerpy
python setup.py develop
cd ..
```

Run causal effect estimation

```(bash)
cd algorithm
python main.py
cd ..
```


## Requirements

pytorch 2.1.2

numpy 1.24.3

scipy 1.10.1

networkx 3.1

matplotlib 3.7.1
